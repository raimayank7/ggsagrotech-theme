# ggsagrotech-theme

Website files for [www.ggsagrotech.com](https://www.ggsagrotech.com/), served at `https://assets.ggsagrotech.com/assets/`.

| File | What it does |
|---|---|
| `assets/ggs.css` | Site design |
| `assets/ggs.js` | Site features (menu, search, products, WhatsApp enquiry, tools) |
| `assets/pages/*.html` | Page content: each Blogger page loads its file from here, so editing a file and pushing updates the live page |

Designed & Developed by [Nivesh Sahayak](https://www.niveshsahayak.in/).
